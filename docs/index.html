About & Core Concepts

Parallel human and AI workspaces without port conflicts, container clashes, or test database collisions.

Isolation Model
Dedicated Worktrees & Deterministic Slots
Instead of in-place branch switching (git checkout), every branch lives in its own isolated directory:
  • Deterministic Slot ID: Sequential numeric slot (1, 2, 3...) under advisory lock.
  • Port Offsets: Effective Port = Base Port + Slot ID.
  • Test DB Isolation: Injects TEST_DATABASE_NAME and CLAW_TEST_DB per slot.
  • Environment & Caches: Writes .env.worktree and symlinks node_modules, target, .venv.
$git claw feature start auth-jwt
→Assigned Slot 1 (PORT_WEB: 8001)
→TEST_DATABASE_NAME=test_app_slot_1
→Created ~/.git-claw/worktrees/app/auth-jwt

Setup & Installation

Install prebuilt binaries or build with Cargo, then enable shell integration.

Prebuilt Binaries & Cargo
Download prebuilt archives from GitHub Releases (Linux GNU/musl, macOS ARM64/x64, Windows) or install via Cargo. Git exposes git-claw automatically as git claw.
$cargo binstall git-claw
$cargo install git-claw
$git-claw --version
Shell Hook & Auto-Completion
Enable shell-hook for opt-in --cd on start and automatic return to main on finish/drop. Also generate completions for Fish, Bash, or Zsh.
$eval "$(git claw shell-hook bash)"
$eval "$(git claw shell-hook zsh)"
$git claw shell-hook fish | source
$git claw completion fish > ~/.config/fish/completions/git-claw.fish

Getting Started

Zero configuration out of the box, with guided project initialization.

Initialize Repository (.git-claw.toml)
Scans .env files, Compose files, .python-version, uv.lock, .venv, and .nvmrc. Guards against overwriting existing config unless confirmed or --yes is passed.
$git claw init
$git claw init --yes
$git claw init --yes --json

Features, Bugfixes & Hotfixes

Develop and ship parallel branches safely.

Start a worktree
Creates feature|bugfix|hotfix/<name>, allocates a Slot ID, generates .env.worktree, and symlinks shared caches.

Flag --cd: navigate active shell into the worktree (default stays on primary repo).
Flag --isolated: skips shared cache symlinking.
$git claw feature start auth-flow
$git claw feature start auth-flow --cd
$git claw bugfix start fix-login --isolated
$git claw hotfix start sec-patch
Work inside & publish
Open in your editor, run commands with .env.worktree loaded, or push with upstream tracking.
$git claw open auth-flow
$git claw run auth-flow npm test
$git claw cd auth-flow
$git claw feature publish auth-flow
Finish up
Runs pre_finish hooks (blocks merge on failure unless --force), merges into main_branch, removes worktree and local/remote branches (preserve remote with --keep-remote / -k), and frees the Slot ID.
$git claw finish auth-flow
$git claw finish auth-flow --keep-remote
$git claw finish auth-flow --force

Docker, Test DBs & Environments

First-class isolation for full-stack Python, Django, Node, and Docker Compose projects.

Docker Compose & Test DB Isolation
With [docker] configured, git-claw generates docker-compose.override.yml using container_name: !reset, sets shared services (postgres, redis) to scale: 0, attaches external networks, and injects TEST_DATABASE_NAME / CLAW_TEST_DB.
[files]
copy = [".env"]

[docker]
compose_file = "docker-compose.yml"
network = "app_network"
shared_services = ["postgres", "redis"]
Python, Node & Herdr Integration
Propagates .python-version (PYENV_VERSION), symlinks .venv for uv/venv (VIRTUAL_ENV + PATH), copies .nvmrc/.node-version/.envrc, and auto-opens branches in Herdr when HERDR_ENV=1.
[environment]
type = "pyenv"
name = "3.12.0"
copy_files = [".python-version"]

# Opt out of Herdr if needed:
$CLAW_DISABLE_HERDR=1 git claw feature start api

AI Agents & Automation (--json)

Deterministic single-document JSON payloads across inspection and lifecycle commands.

Machine-Readable JSON Output
Pass --json to list, start, publish, finish, spike drop, or init --yes. Hook and diagnostic output stays off stdout so callers can parse stdout cleanly.
$git claw list --json
$git claw feature start auth --json
$git claw feature publish auth --json
$git claw finish auth --json
$git claw spike drop poc --json

Spikes (Disposable POCs)

Experimental exploration intended to be discarded without merging.

Create and Drop Spikes
Spikes create a temporary workspace on spike/<name>. Dropping safely destroys the directory, deletes the branch, and releases the Slot ID.
$git claw spike start vector-db
$git claw spike drop vector-db

Releases (SemVer & Changelog)

Automated Commitizen-style releases and manifest synchronization.

Automated Conventional Commit Tagging
Run on a clean main branch without arguments:
  • Infers SemVer bump (Major: feat!:, Minor: feat:, Patch: fix:).
  • Generates/updates CHANGELOG.md grouped by category.
  • Updates Cargo.toml (Rust) or pyproject.toml / project.toml (Python).
  • Synchronizes lockfiles (Cargo.lock, uv.lock).
  • Commits chore: release <version> and tags main.
$git claw tag

# Explicit version override:
$git claw tag v1.2.0

Commands Quick Reference

Complete syntax table for all git-claw actions.

Command Action
git claw init [-y] [--json] Initialize or update repository configuration
git claw list [--json] Display active worktrees, assigned slots, and ports
git claw feature|bugfix|hotfix start <name> [--isolated] [--cd] [--json] Create and start isolated worktree
git claw publish [<name>] [--remote <r>] [--json] Push worktree branch to remote with upstream tracking
git claw finish [<name>] [--force] [-k|--keep-remote] [--json] Verify tests, merge into main, delete branch, and cleanup
git claw spike start <name> [--isolated] [--cd] [--json] Create disposable experiment worktree
git claw spike drop <name> [--json] Discard disposable experiment worktree and branch
git claw open|cd [<name>] Open workspace in editor or print worktree path
git claw run [<name>] <command...> Execute command inside worktree with env injected
git claw tag [<version>] Commitizen auto bump or explicit release tag
git claw shell-hook [bash|zsh|fish] Emit shell auto-cd wrapper script
git claw completion <shell> Generate shell auto-completion script
